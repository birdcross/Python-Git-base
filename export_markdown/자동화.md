# 자동화 프롬프트

총 5개의 프롬프트

## 1. 이메일 자동 요약

- 카테고리: 자동화
- 즐겨찾기: ⭐
- 조회수: 0회

### 프롬프트

새로운 이메일이 도착하면 제목과 본문을 분석하여 핵심 내용을 3줄 이내로 요약하고 중요도를 판단해주세요.

---

## 2. 고객 문의 자동 분류

- 카테고리: 자동화
- 즐겨찾기: ☆
- 조회수: 0회

### 프롬프트

고객 문의 내용을 분석하여 배송, 제품불량, 환불, 결제, 사용문의, 기타 중 하나의 카테고리로 자동 분류해주세요.

---

## 3. 회의록 자동 정리

- 카테고리: 자동화
- 즐겨찾기: ⭐
- 조회수: 0회

### 프롬프트

회의 내용을 입력받아 주요 안건, 결정사항, 담당자, 완료기한을 자동으로 추출하여 표 형태로 정리해주세요.

---

## 4. 파일 자동 분류

- 카테고리: 자동화
- 즐겨찾기: ☆
- 조회수: 0회

### 프롬프트

파일 이름과 확장자를 분석하여 문서, 이미지, 동영상, 압축파일, 기타로 분류하고 적절한 폴더 이름을 제안해주세요.

---

## 5. 뉴스 자동 요약

- 카테고리: 자동화
- 즐겨찾기: ☆
- 조회수: 0회

### 프롬프트

수집된 뉴스 기사 내용을 분석하여 제목, 핵심 내용, 주요 키워드, 한줄 요약으로 정리해주세요.
